PropTech / Web App

iAgentData

Property register for Malaysian industrial, commercial and land agents

Challenge
Twenty filters in one flat list pushed the register table below the fold on a normal laptop.
Solution
A grouped, collapsible filter rail, four frozen table columns, a two-step owner → property flow, and separate admin and agent shells.

Built with

  • Next.js
  • React
  • Supabase
  • Zero WCAG 2.2 AA contrast failures across 19 screens
  • 33 / 33 admin and 41 / 41 agent-role checks passing
  • No horizontal overflow from 1440px down to 390px
  • Agents see their own listings plus the groups they join
